# Dataset QC report

Generated by the growth-plate target-discovery pipeline. Every figure below is
read back from pipeline artifacts (download manifest, per-stage QC JSON).

## Access constraints in this environment

- `ftp.ncbi.nlm.nih.gov` is blocked by the session egress policy (HTTP 403). All GEO
  retrieval therefore used the HTTPS endpoint `https://www.ncbi.nlm.nih.gov/geo/download/`,
  which serves the identical supplementary files.
- The GWAS Catalog REST trait endpoints returned HTTP 500/404, so height associations were
  taken from the bulk ontology-annotated release on `ftp.ebi.ac.uk` (reachable over HTTPS).
- No R is available, so limma's moderated t-test was reimplemented in Python
  (`destats.py`, empirical-Bayes variance shrinkage) and PyDESeq2 was used for raw counts.

## CRISPR screen QC (GSE225878)

- Genome-wide day-4 vs day-15 LFC correlation is **r = 0.012** across all 22,634 genes, i.e. the two timepoints are essentially uncorrelated in bulk.
- That is noise-dominated rather than a screen failure: restricted to genes with real day-15 signal (-log10 p > 2, n = 168) the correlation rises to **r = 0.558**.
- Cross-library replication is good: primary vs secondary screen at day 15 gives **r = 0.690** (n = 237).
- Day 15 is therefore treated as the informative timepoint and day 4 as supporting evidence.
- **Guide multi-mapping artifact:** 3,792 genes have >50% of their sgRNAs shared with another gene (pseudogene and paralogue families such as `Btbd35f*`, `Gm*`, histone clusters, `Smok3a/b/c`). These inherit each other's log-fold changes with spuriously perfect guide consistency. Before filtering, **139 of 147** genome-wide-only candidates were such artifacts; they are excluded from CRISPR_CAUSAL.

for chondrocyte identity and hypertrophy. `Sufu`/`Ptch1` (Hedgehog brakes) and `Gnas` score
positive while `Prkar1a` — the opposing arm of the same PKA axis — scores negative, which is
the internally consistent behaviour a real maturation readout should show.

- Screen contrast: guide LFC = top10% CD200-high vs bottom10% CD200-low (per GEO data-processing field)
- `Cd200` itself is +5.09 log2 in CD200-high at day 15, confirming the sort worked.
- CD200-high cells resolve as **mature/hypertrophic-like**.

## Bulk dataset QC

- **GSE114919**: the submitted mouse and rat matrices had passed through Excel, which converted
  26 gene symbols of the MARCHF/SEPTIN families into date serial numbers, and left one stray text
  cell in the numeric body. Symbols were recovered deterministically from the serial
  (epoch 1899-12-30 → `1-Mar` → `Marchf1`); the stray cell was coerced to NA.
  Mouse: 20,179 genes × 29 samples; rat: 15,186 × 30. Mouse–rat correlation for the
  young-vs-old tibia contrast is r = 0.39, i.e. independent cross-species support.
- **GSE87605 / GSE9160** deposited CEL files only. Without R/affy these could not be re-normalised
  from raw, so submitter-processed per-sample VALUE tables were pulled from the SOFT full view and
  quantile-aligned within series. **This is a deviation from ideal practice** and means the human
  zonal layer inherits the submitters' normalisation.
- **GSE9160** has n = 2 per zone, which is too thin for reliable per-gene inference; it is used
  for zone-specificity effect sizes only, never for p-value-based claims.

## Single-cell QC

Each dataset was QC'd separately (≥500 genes, ≥1000 UMI, ≤15% mitochondrial), doublets removed
with Scrublet, clustered with Leiden, and annotated by marker-panel scores. Expression was then
**pseudobulked by (biological sample × cell state)** — individual cells are never used as
biological replicates.

| dataset | samples | cells raw → post-QC | doublets removed | states recovered |
|---|---:|---|---:|---|
| GSE125464 | 1 | 6,794,880 → 8,577 | 0 | prehypertrophic, proliferative, resting |
| GSE201605 | 6 | 23,409 → 15,620 | 0 | hypertrophic, prehypertrophic, proliferative, resting |
| GSE231795 | 10 | 85,972 → 80,896 | 0 | hypertrophic, proliferative, resting |
| GSE244881 | 1 | 6,794,880 → 654 | 0 | hypertrophic, prehypertrophic, resting |
| GSE271634 | 1 | 7,262 → 6,731 | 0 | prehypertrophic, proliferative, resting |
| GSE288529 | 1 | 12,636 → 10,910 | 0 | hypertrophic, prehypertrophic, proliferative, resting |

Note that several of these series are single-sample (n = 1 mouse), so they contribute
state-specific expression profiles but cannot support within-dataset replicate statistics.
Only GSE231795 (10 samples) and GSE201605 (6 samples) carry true biological replication.

## Limitations

- **GSE76157** deposited a single plate-based expression matrix with no per-sample supplementary
  files; it was downloaded but is not part of the pseudobulk consensus, which requires
  sample-level 10x matrices.
- Affymetrix series were not re-normalised from CEL (no R in this environment).
- `Adamts17` knockout was not confirmed at the transcript level in GSE123076, so that
  perturbation contributes little evidence.
- Human height GWAS attribution uses the catalog's positional `MAPPED_GENE` field. This is
  **locus-level evidence, not causal gene assignment**, and 13,063 genes carry some height
  association because height is extremely polygenic — it is therefore scored by strength
  (number of independent loci, best p-value), never as a binary flag.
